# 📈 Planilhas de Cotações B3 em Tempo Real - DARF 6015

Este repositório contém ferramentas automatizadas para o acompanhamento dos principais índices da bolsa brasileira (B3). O projeto faz parte do ecossistema [darf6015.com.br](https://darf6015.com.br), focado em auxiliar investidores no controle de ativos e obrigações fiscais.

## 📊 Ferramentas Disponíveis

As planilhas utilizam as funções do Google Finance para fornecer dados atualizados de abertura, máxima, mínima e variação das últimas 52 semanas.

### 1. Índice Bovespa (IBOV)
Monitoramento das principais ações que compõem o carro-chefe da nossa bolsa.
* **Acesso Direto:** [Abrir Planilha IBOV](https://docs.google.com/spreadsheets/d/1oe6IjubeuHSAflftJqikP5LfNDhgUh4MgPenQhphVlw/htmlview)
* **Fazer uma Cópia:** [🔗 Clique aqui para copiar](https://docs.google.com/spreadsheets/d/1oe6IjubeuHSAflftJqikP5LfNDhgUh4MgPenQhphVlw/copy)

### 2. Índice de Small Caps (SMLL)
Focado em empresas de menor capitalização com alto potencial de crescimento.
* **Acesso Direto:** [Abrir Planilha Small Caps](https://docs.google.com/spreadsheets/d/1gNHxMxnnHBJpxOQ0P3Hngi7CdfEmGChFv1KEWLBaslQ/htmlview)
* **Fazer uma Cópia:** [🔗 Clique aqui para copiar](https://docs.google.com/spreadsheets/d/1gNHxMxnnHBJpxOQ0P3Hngi7CdfEmGChFv1KEWLBaslQ/copy)

---

## 🚀 Como usar
1. Clique no link de **"Fazer uma Cópia"** acima.
2. A planilha será salva automaticamente no seu Google Drive.
3. Os dados são atualizados em tempo real (com o delay padrão do Google Finance).
4. Você pode personalizar as colunas ou adicionar novos tickers conforme sua necessidade.

## 🛠️ Sobre o Projeto
O **DARF 6015** é um portal criado para simplificar a vida do investidor pessoa física. Além destas planilhas, oferecemos conteúdo prático sobre cálculo de Imposto de Renda em ações, day trade e swing trade.

Para entender mais sobre as regras da Receita Federal e como organizar seus investimentos, visite nossa página:
